🍍 There is / There are — jak grać?

  1. Kliknij 🎲 LOSUJ (albo spacja). Maszyna losuje jedzenie i zadanie.
  2. Zadania: zdanie z There is / There are, z There isn't / There aren't, prośba Can I have a / some …, please?, opinia (It's delicious!) albo zagadka — opisz jedzenie, nie mówiąc jego nazwy.
  3. Pamiętaj: jedna rzecz → There is a / an; wiele rzeczy → There are some; czegoś nie da się policzyć (cheese, bread) → There is some.
  4. W przeczeniu: There isn't a …, There isn't any …, There aren't any …
  5. Powiedz zdanie na głos albo wpisz je w pole (nieobowiązkowo) — sprawdzimy, czy jest dobrze.
  6. Kliknij 👀 Przykładowe odpowiedzi (Enter) — zobaczysz przykłady i usłyszysz lektora 🔊.
  7. Zagadka: klasa zgaduje, a odpowiedź pokaże się po kliknięciu.
  8. Nauczyciel: 🖨️ Karta pracy drukuje 12 losowych zadań z przykładowymi odpowiedziami.

📘 Ściąga — There is / There are

✔ There is / There are

  • jedna rzecz: There is a pineapple. · There is an onion.
  • wiele rzeczy: There are some grapes.
  • niepoliczalne: There is some cheese / bread / rice.
  • skrót: There's = There is

✖ There isn't / There aren't

  • There isn't a lemon.
  • There isn't any jam.
  • There aren't any biscuits.
  • w przeczeniu any, nie some

🙋 Prośba i opinia

  • Can I have a tomato, please?
  • Can I have some pasta / grapes, please?
  • jedna rzecz / niepoliczalne: It's delicious!
  • wiele rzeczy: They're horrible!

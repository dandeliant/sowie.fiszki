ℹ️ Jak grać?

  1. Kliknij 🎲 Wylosuj — wylosuje się typ zdania (+ / − / ?), czas (now / yesterday), kwantyfikator i rzeczownik.
  2. Zbuduj poprawne zdanie po angielsku, np.
    (+)(now)(dużo)(obraz) → There are a lot of paintings.
  3. Kliknij 👁️ Pokaż zdanie, żeby sprawdzić i zobaczyć tłumaczenia.
  4. 🔊 posłuchaj poprawnej wymowy. Filtruj typ zdania i czas u góry.
Zasady:
• now → there is / there are  •  yesterday → there was / there were
• policzalne (liczba mnoga) → are/were, niepoliczalne → is/was
• + : a/an, some, no, a lot of, lots of, a few / a little, too many / too much
• − : any, many / much, a lot of
• ? : any, many / much, a lot of, how many / how much
